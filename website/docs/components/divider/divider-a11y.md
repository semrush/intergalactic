## What component has

### Roles and attributes

The following list describes roles and attributes that the component already has.

Table: Roles and attributes

| Attribute                                | Usage                                                                                                           |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `role="separator"`                       | Identifies the element as a divider that separates and distinguishes sections of content or groups of elements. |
| `aria-orientation="horizontal/vertical"` | Indicates the element's orientation.                                          |
