## Description

**BaseTrigger** is a foundational component for creating triggers with button-like behavior, resembling buttons, links, or filters.

`BaseTrigger` has the following types for using in different scenarios:

- `ButtonTrigger`
- `FilterTrigger`
- `LinkTrigger`
